# Local Testing (Summary)

Source: Fynd Commerce Themes - Local Testing.

## Core Areas
- Mandatory features: use marketplace testing assets + review checklist.
- Performance: GTmetrix A, page speed < 1.4s.
- Browser compatibility: test Chrome/Safari/Firefox + tools like BrowserStack.

## Additional Suggestions
- Disable JS in DevTools to check no-JS behavior.
- Include external testers for unbiased feedback.

## Checklist Highlights
- Home page: required sections, total ~15 sections.
- Header: logo, navigation, fallback logo, alignment, L1/L2/L3 nav, mega menu if applicable.
- Footer: links, copyright/legal, payment icons, social, newsletter.
- Sections: hero, collections, slideshow, gallery, banners, video, testimonials, extensions.
- Pages: account, PLP/PDP, cart/checkout, wishlist, search, landing pages, blog, FAQ, 404, policies.
- Rich media: 3D/AR, video controls, variants with media.
