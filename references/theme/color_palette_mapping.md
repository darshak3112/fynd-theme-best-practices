# Color Palette Mapping (Summary)

Source: Fynd Commerce Themes - Color Palette Mapping.

## Usage
- Use CSS variables with fallback values, e.g.:
  `color: var(--textHeading, #26201a);`

## Key Groups
- General colors: primary, secondary, accent, link, background, text, buttons.
- Sale/discount: badge background/text, discount text, timer.
- Header/Footer: background, nav, icon, footer text.
- Advanced: dialog, overlay, divider, success/error/info alerts.

## Note
- Variables are mapped from theme palette settings (generalColor/advanceColor).
