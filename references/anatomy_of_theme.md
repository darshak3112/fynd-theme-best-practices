# Anatomy of Theme (Summary)

Source: Fynd Commerce Themes - Anatomy of Theme.

## Core Pieces
- Themes are composed of **pages**, **sections**, and **blocks**.
- Templates cover pages like home, PLP, cart, etc.
- `fdk`-prefixed action components are available across the theme for actions (e.g., add to cart).

## Seller Customization
- Sellers customize via Theme Editor.
- Developers expose customization through:
  - Modular sections/blocks.
  - Global + page-level settings.
