# Theme Get Started (Summary)

Source: Fynd Commerce Themes - Get Started.

## Prerequisites
- Node.js v18+, Git, Fynd Partners account, and a development company in Partner Panel.

## Quick Start (FDK CLI)
- Install CLI: `npm install -g @gofynd/fdk-cli`
- Login: `fdk login`
- Create theme: `fdk theme new --name <theme_name> --template <template_name> --company-id <company_id>`
- Serve locally: `fdk theme serve` (default http://localhost:5001)
- Sync to partner panel: `fdk theme sync`
- Open theme in panel: `fdk theme open`
