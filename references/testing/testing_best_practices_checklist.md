# Testing Best Practices Checklist (Summary)

Source: Fynd Commerce Themes - Testing Best Practices Checklist.

## Checklist
- Functionality: verify all features across use cases.
- User experience: navigation, consistency, ease of use.
- Load testing: handle expected traffic without degradation.
- Automated tests: smoke tests for core flows.
- Accessibility: WCAG 2.1, Axe/Lighthouse, keyboard/screen reader.
- Cross-browser/device: Chrome/Firefox/Edge, desktop/mobile.
