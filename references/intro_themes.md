# Introduction to Themes (Summary)

Source: Fynd Commerce Themes - Introduction.

## Core
- Themes define the storefront look & feel and user interactions.
- Built with React v18.
- Can build custom themes, customize existing ones, or sell themes.
- Extensions can enhance theme functionality.

## Monetization Paths
- Theme customization work.
- Bespoke themes for a single seller.
- Extensions integrated with themes.

## Tools
- FDK CLI for create, run locally, sync, and publish themes.
